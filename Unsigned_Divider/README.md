# RTL Design & FPGA Implementation of Unsigned Divider

## Overview
8-bit by 4-bit multi-cycle unsigned divider implemented in Verilog HDL using repetitive subtraction.

## Features
- Datapath and Control Path Architecture
- FSM-based Controller
- Division-by-Zero Detection
- Self-checking Testbench
- Nexys A7 FPGA Implementation
- 100 MHz Timing Closure

## Tools
- Verilog HDL
- Vivado 2025.1
- Nexys A7 FPGA

## Results
- LUTs: 29
- FFs: 23
- Timing Met @ 100 MHz
